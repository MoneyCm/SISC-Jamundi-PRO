## Flujo r·pido para los 35 territorios faltantes

1) Extraer nombres no mapeados desde backend:

```bash
python backend/export_unmapped_dashboard.py `
  --base-url http://127.0.0.1:8000 `
  --min-location-count 1 `
  --out-csv backend/data/unmapped_territorios.csv `
  --out-json backend/data/unmapped_territorios.json
```

2) (Opcional) Validar contra polÌgonos actuales y sugerir aliases:

```bash
python backend/validate_map_localidades.py `
  --source-file backend/data/unmapped_territorios.csv `
  --source-column name `
  --geojson backend/data/barrios_jamundi_valle.geojson backend/data/barrios_jamundi_valle_extra.geojson `
  --aliases-out backend/data/barrios_official_aliases_autogenerated.json `
  --dry-run
```

3) Generar plantilla GeoJSON de stubs (si prefieres preparar y luego reemplazar geometrÌas):

```bash
python backend/make_unmapped_geojson_stubs.py `
  --source backend/data/unmapped_territorios.csv `
  --source-column name `
  --out backend/data/barrios_jamundi_valle_extra.geojson
```

4) Pipeline unico (1 comando):

```bash
python backend/unmapped_pipeline.py \
  --base-url http://127.0.0.1:8000 \
  --min-location-count 1 \
  --out-json backend/data/unmapped_territorios.json \
  --out-csv backend/data/unmapped_territorios.csv \
  --aliases-out backend/data/barrios_official_aliases_autogenerated.json \
  --stubs-out backend/data/barrios_jamundi_valle_extra.geojson
```

Resultado:
- `unmapped_territorios.json` y `.csv` con territorios no ubicados
- `barrios_official_aliases_autogenerated.json` con sugerencias de alias
- `barrios_jamundi_valle_extra.geojson` con stubs para reemplazar por polÌgonos reales
